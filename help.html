Colorbars Help

How matching, styling, segments, and Fleet server detection work.

Overview

This extension shows a colored bar at the top of matching pages. Rules are evaluated with URL-component precedence first and list order second.

Toolbar Popup

  • Click the Colorbars toolbar icon for quick controls; it follows the theme set in Settings.
  • All sites is the master switch — turning it off hides every bar everywhere.
  • This page enables/disables the rule matching the current tab; it mirrors that rule's switch in Settings.
  • Disabling globally remembers each rule's state. Re-enabling — or turning on a rule from the popup or Settings — restores the previous states.
  • When a timed Snooze is active, the popup shows it with a Resume button.
  • Create rule for this page quickly adds a rule for the current tab: it pre-fills the name from the domain, you enter the bar text and pick a color from your swatches, and all other settings come from your default style.
  • Wildcards are on by default (the rule matches the whole site); turn them off to flag only the exact page. If a rule already covers the page, the popup offers to edit it instead of creating a duplicate.
  • After creating, a short confirmation with a bar preview offers Edit rule, which opens Settings expanded on the new rule.

Global Settings

  • Categories below are collapsible panels (like rules); each summary shows its current state.
  • Enable all rules — the same master switch as the popup's "All sites".
  • Snooze — temporarily hide all bars for 1 hour or until tomorrow; bars auto-return when the snooze ends.
  • Default style for new rules — height, placement, colors, font, and transform applied to each newly-added rule.
  • Domain blocklist — one domain per line where Colorbars never shows, even if a rule matches. Supports * wildcards; a bare domain also covers its subdomains.
  • Tab indicator — replaces the tab's favicon with a solid rounded tile in the matched rule's color, so you can spot flagged tabs at a glance. It appears only on background tabs; the active tab keeps its real favicon so the page you're viewing is never obscured. Extensions can't draw on the tab itself, so this rides on the favicon.

Theme

  • The settings page supports Light, Dark, and Auto themes.
  • Auto follows your operating system appearance (light or dark) and switches live when the system setting changes.
  • The chosen theme is stored in chrome.storage.sync and applies to the settings and help pages.

Rule Matching

  • Domain Pattern mode accepts a single wildcard pattern. Example: *.example.com/admin/*.
  • With Wildcards on, an omitted scheme and path are wildcarded (any scheme, any path); everything else matches as typed. You can place * anywhere to wildcard any part of the URL. For subdomains, prefix the host with *. (e.g. *.example.com) — note that *.example.com matches subdomains but not the bare example.com.
  • URL Components mode supports scheme/prefix, host, path, port, and query options.
  • Domain Pattern mode and URL Components mode are mutually exclusive to avoid conflicts.
  • When multiple rules match, earlier URL components take precedence (scheme, host, path, port, query).

Styling

  • Per-rule Bar Color, Bar Opacity, Text Color, Text Opacity, and font settings are supported.
  • Blur frosts the page behind the bar. It is available only when Bar Opacity is below 1 (a fully opaque bar has nothing to blur), and remembers its value if you disable then re-enable it.
  • Bar height is configurable per rule, and font size is constrained by bar height.
  • The bar pushes page content down, and naturally overlays content as the page scrolls beneath it.
  • Letter spacing is constrained by available window width and updates on resize.
  • Built-in system fonts are available from the Font dropdown.

Color Picker & Swatches

  • The Background and Text color controls open a custom color picker.
  • The picker button itself shows the current color (with its hex value).
  • Pick a color with the saturation/brightness box and hue slider, or type a hex value.
  • Click + to save the current color as a swatch. Swatches are shared across all rules.
  • Click a swatch to apply it; shift-click a swatch to remove it.

Bar Text & Segments

  • A rule's bar can contain multiple text elements ("segments"): plain Text, Page Title, Fleet Server Info, and Browser Info. Add as many as you need.
  • Page Title shows the page's own title ({title}) and updates as it changes — handy on sites whose sticky-header title gets hidden behind the bar.
  • Each segment is placed Left, Center, or Right.
  • Segments are placed into independent zones and never overlap.
  • Segments sharing a zone stack horizontally, in list order.
  • Click any text in the bar to copy it to the clipboard (it briefly shows "Copied").
  • Use the per-rule drag-and-drop mock-up to drag any segment (by its chip or the ⠿ handle) into a zone, and drag segments within a zone to reorder them.
  • Prefer dropdowns to dragging? Each segment's Justification dropdown sets its placement directly.
  • Tip: to show version and branch in different places, add two Fleet Server Info segments — e.g. one templated {version} on the left and another {branch} on the right.

Fleet Server Detection

  • Add a Fleet Server Info segment to show the running Fleet server's version and branch in the bar.
  • The extension detects a Fleet server on any domain by reading <origin>/version and checking its response shape, so the value can differ per tab.
  • The display template supports placeholders: {version}, {branch}, {revision}, {go_version}, {build_date}, {build_user}.
  • The segment only renders on tabs whose server is detected as Fleet; otherwise it shows nothing.
  • An optional API token field is available for the authenticated /api/latest/fleet/version endpoint when the public /version is unavailable. The token field is masked and stored locally.

Tab Title

  • Per rule, rename the browser tab on matching pages via the Tab Title section.
  • Prepend/Append add your text to the page's title but revert to the real title when the tab is focused — so the true title is still there when you look. Overwrite replaces it entirely and persists (with a warning).
  • Enable Prepend GitHub issue/PR number to turn a GitHub issue titled "Add option…" into "#51484 - Add option…" in the tab. It persists on focus and never changes the page or the issue.
  • The page's real title is preserved internally, so a Page Title bar segment still shows the true title even while the tab is renamed.

Browser Info

  • Add a Browser Info segment to show the current tab's browser, version, platform, and architecture in the bar.
  • Placeholders: {browser}, {version} (full version), {major}, {platform} (e.g. macOS, Windows), and {arch} (e.g. arm64, x86_64). Example: {browser} {version} ({arch}).
  • The full version, platform, and architecture come from the browser's User-Agent Client Hints; other browsers fall back to the user-agent string. No network request is made.
  • The build channel ("Official Build") is not available to extensions, so it can't be shown.

Usage

  • Open extension options from chrome://extensions.
  • Add rules and collapse finished rules to keep the list compact.
  • Errors are shown as brief notifications.
